# Orientación Educacional y Sociolaboral – 3.er Curso

Material de estudio para el egreso de la Educación Media y la preparación del Examen Final 2026.

**Colegio Nacional Don Jorge Gayoso** · Paraguay · Año lectivo 2026

## Contenido

| Archivo | Descripción |
| :--- | :--- |
| `index.html` | Página de entrada del sitio |
| `tarjetas_estudio_egreso.html` | 21 tarjetas interactivas de repaso (3 ejes temáticos) |
| `cuestionario_50_preguntas.html` | Cuestionario integral de 50 preguntas con respuestas clave |

## Ejes temáticos

1. **Identidad y Madurez** – autoconocimiento, resiliencia, valores, autonomía.
2. **Orientación Vocacional** – oferta universitaria y técnica, mallas curriculares, acreditación, becas.
3. **Inserción Laboral** – currículum vitae, entrevistas, habilidades blandas, marca personal.

## Uso

El sitio funciona en cualquier navegador, sin instalación. Basta abrir `index.html`
o visitar la dirección del sitio publicado.

### Atajos de teclado (tarjetas)

| Tecla | Acción |
| :--- | :--- |
| `←` / `→` | Navegar entre tarjetas |
| `Espacio` | Girar la tarjeta (pregunta / respuesta) |
| `M` | Marcar tarjeta como dominada |
| `R` | Barajar aleatoriamente |

## Requisito de conexión

Las tarjetas utilizan el framework de estilos Tailwind a través de CDN y una tipografía
de Google Fonts. Para su correcto funcionamiento visual se requiere conexión a internet.

## Referencias normativas

- Ley Nº 4995/13 de Educación Superior de la República del Paraguay.
- Ley Nº 213/93 Código del Trabajo del Paraguay.
- Ley Nº 98/92 de la Organización del Instituto de Previsión Social (IPS).
- MEC – Programa de Estudio: Orientación Educacional y Sociolaboral, 3.er Curso.
